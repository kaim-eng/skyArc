# Explorer Jupiter-C visual asset

Source: [NASA Explorer Jupiter-C Rocket](https://science.nasa.gov/3d-resources/explorer-jupiter-c-rocket/)

Creator/credit: NASA/Michael D. Carbajal.

The runtime `Explorer_JupiterC_NoStage1.usdc` is a Stage-1-free derivative prepared for the skyArc
simulation. It remains visual-only; the simulation's hidden cylinder owns mass and collision.
